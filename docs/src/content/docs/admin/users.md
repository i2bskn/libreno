---
title: ユーザーを管理する
description: ユーザーの追加と招待リンク、ロールの変更、多要素認証のリセット、ユーザーの削除。
---

管理者はWebの「ユーザー管理」（`/users`）でユーザーの一覧を見られます。ここではユーザーを追加したり、ロールを変えたり、ログアウトさせたり、ユーザーを削除したりできます。パスワード認証ではパスワードの再設定と多要素認証のリセットもできます。

## ユーザーを追加する

### パスワード認証

パスワードを空欄にして追加すると招待リンクが発行されます。本人がリンクを開いてパスワードを決めるとログインできます。

- リンクは7日間、1回だけ使えます。
- リンクは発行したときにしか表示されないので、その場でコピーして本人に伝えてください。
- 招待リンクのOriginは、有効な`APP_ORIGIN`があればそれ、なければ管理者が開いている画面のOriginです。
- 招待リンクを失くしたときや期限が切れたときは、「招待リンクを再発行」で新しいリンクを発行できます。前のリンクは使えなくなります。
- 管理者がパスワードを再設定しても、招待は使われたことになります。

### OIDC認証

OIDC認証でユーザーを追加すると、その人はIdPでログインすると使えるようになります（[OIDC認証にする](/libreno/admin/oidc/)）。

## 多要素認証をリセットする

「多要素認証をリセット」は、その人の認証方法（パスキー・認証アプリ・リカバリーコード）をすべて削除し、すべての端末でログアウトさせます。MCPの接続も切れます。パスワードはそのままです。

:::caution
リセット後はパスワードだけで新しい認証方法を登録できます。本人確認をしてから実行し、すぐにログインして登録してもらってください。
:::

自分自身の多要素認証はリセットできません。

## ユーザーを削除する

:::danger
ユーザーを削除すると、その人の個人スペースも中身（ページ・ゴミ箱のページ・フォルダ・添付ファイル）ごと削除されます。元に戻せません。D1をTime Travelで戻しても、R2から消えた添付ファイルは戻りません。
:::

- ほかのスペースでその人が作成・編集したページは残ります。
- メンバー指定のスペースのメンバーからも外れます。
- 自分自身は削除できません。最後の管理者を削除することも一般に戻すこともできません。
- まだログインしていない人を削除すると、招待の取り消しになります。
- OIDC認証の場合、削除した人はログインできなくなります。もう一度使ってもらうには、ユーザー管理で追加し直します（新しいユーザーとして作られます）。
