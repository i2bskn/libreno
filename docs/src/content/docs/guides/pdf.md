---
title: PDFで出力
description: ページをA4のPDFにする方法と、ブラウザの印刷とサーバーでの出力の違い。
---

ページの「…」メニューの「PDFで出力」から、ページをA4のPDFにできます。プレビューを見ながら体裁と表紙の項目を入力して出力します。入力した内容は保存されません。

## 体裁

| 体裁 | 内容 |
| --- | --- |
| 正式（表紙あり） | 1ページ目が表紙になり、タイトル・宛先・日付・版数・発行者・機密表示を載せます |
| シンプル | 本文の先頭にタイトルを置きます |

- 本文のページの下にページ番号を、機密表示を入力したときは右上に機密表示を入れます。ページ番号の総数には表紙を含みます。
- 発行者と機密表示の既定値は、管理者が画面の「発行者と機密表示を既定として保存」で全員分を保存できます。

## 出力の方法

| 方法 | 使い方 |
| --- | --- |
| ブラウザの印刷（既定） | 印刷ダイアログで「PDFに保存」を選びます。ページ番号と機密表示のヘッダーはChromeでのみ入ります |
| サーバー（Browser Rendering） | 設定で`PDF_RENDERER`を`browser`にすると、サーバーで作ったPDFをダウンロードできます。このときもブラウザの印刷を使えます |

## サーバーで作る場合

- サーバーで作るPDFには、このサイトにある画像（添付ファイル）だけが入ります。ほかのサイトの画像は代わりのテキストになります。
- ログインしている人は見られるページを指定すれば任意のHTMLをPDFにできます。PDFを作るブラウザではJavaScriptを動かさず、外部への通信もさせません。回数の制限はありません。
- Browser Renderingは無料プランでは1日10分までです（[動作環境](/libreno/getting-started/requirements/#browser-rendering)）。
