スペースごとに見られる人を分けられます。種類は4つです。

| 種類 | 見られる人 | 向いている用途 |
| --- | --- | --- |
| 全員 | 全員 | チーム全体で共有すること |
| 管理者のみ | 管理者だけ | 経理や人事など |
| メンバー指定 | 管理者が選んだメンバーと管理者 | プロジェクトのチームなど |
| 個人 | 本人だけ | 個人のメモ |

AIもWebと同じ権限で動くので、見られないページをAIが読むことはありません。

スペースの種類は作成後に変えられません。

## メンバー指定のスペース

管理者がWebでスペースを作るときに「メンバー指定」を選ぶと、選んだユーザーと管理者だけが見られるスペースになります。見られる人はページの閲覧も編集もできます。

- メンバーを選べるのは管理者だけで、Webからだけ変えられます。スペースのメニューの「メンバーを編集」で選び直します。MCPからはメンバーを見ることも変えることもできません。
- 管理者はメンバーに選ばなくても見られます。管理者をメンバーに選んでおくと、一般に戻したあとも見られます。
- メンバーから外したり管理者を一般に戻したりすると、その人は次の操作から見られなくなります（MCPを含む）。ユーザーを削除するとメンバーからも外れます。
- 外した人のブラウザには、それまでに開いた添付ファイルが最大5分キャッシュに残ります。

## 見られる人が増える移動

ページやフォルダを別のスペースへ移すとき、見られる人の広さは「個人 < 管理者のみ < メンバー指定 < 全員」の順に数えます。MCPで見られる人が増える移動をするときは、AIが利用者に確認します（[MCPで接続する](/libreno/getting-started/mcp/#別のスペースへ移す)）。

## 個人スペースとユーザーの削除

ユーザーを削除すると、その人の個人スペースも中身（ページ・ゴミ箱のページ・フォルダ・添付ファイル）ごと削除されます。元に戻せません。詳しくは[ユーザーを管理する](/libreno/admin/users/#ユーザーを削除する)を参照してください。
