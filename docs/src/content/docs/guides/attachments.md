---
title: 添付ファイル
description: ページに画像とPDFを添付する方法と、保存・削除のしくみ。
---

ページには画像（PNG・JPEG・GIF・WebP）とPDFを添付できます。

| 添付する場所 | 1ファイルの上限 |
| --- | --- |
| Webのページの編集画面 | 10MB |
| MCP（`upload_attachment`） | 2MB |

Webではページの編集画面の「添付ファイル」から追加して、本文にMarkdownとして挿入できます。新しいページは保存してから編集画面で添付してください。

## 添付できるファイル

- ファイルの種類は中身から判定します。SVGやHTMLのようにスクリプトを含められる形式は添付できません。
- ファイル名の拡張子が種類と合わないときは種類の拡張子を末尾に足します。

## 見られる人

- 添付ファイルを見られるのはそのページを見られる人だけです。ページを別のスペースへ移すと添付ファイルも一緒に移ります。
- ゴミ箱にあるページの添付ファイルは見られません。ページを元に戻すとまた見られるようになります。

## 削除

添付ファイルの削除は元に戻せません。本文から参照している箇所は表示されなくなります。

ファイルの中身はR2に保存します。ページを完全に削除すると添付ファイルもR2から削除されます。

| 場合 | R2から消えるとき |
| --- | --- |
| 30日たって自動で削除されたページ | ページと同じ日次の処理 |
| 管理者がゴミ箱から完全に削除したページ | 次の日次の処理（毎日03:00 JST） |
| アップロードの途中で失敗して残ったファイル | 24時間たったあとの日次の処理 |
