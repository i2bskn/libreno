チームの人はWebでページを読んだり検索したりします。ページを開いたときは読むための表示なので、うっかり書き換えることはありません。直したいときは編集ボタンから編集できます。

本文はMarkdownなので、AIが書いたものをそのまま置けます。

## 本文の表示

- Web画面でページの本文（Markdown）を表示するときは、本文中のHTMLをタグとして解釈せずに書いたとおりの文字で表示します。
- 外部の画像は表示しません。
- 本文のコードブロックは右上のボタンでコードだけをコピーできます。マウスで操作するときは、コードブロックにポインタを乗せるとボタンが出ます。

## 編集中の下書き

Webでページを作成・編集している間は、入力中の内容がブラウザ（localStorage）に下書きとして保存されます。

:::caution
この下書きはログアウトしても消えないので、同じブラウザでログインした別の人に見える可能性があります。共有PCでは使わないでください。
:::

同じページを複数のタブで編集すると下書きどうしが上書きし合います。

## ページどうしのリンク

ページの末尾の「このページへのリンク」には、本文でそのページへリンクしているページが並びます。出るのは見ている人が見られるページのうちゴミ箱にないものだけです（新しく更新された50件まで）。

ページのツールバーには次のコピーのボタンがあります。

| ボタン | コピーされるもの |
| --- | --- |
| Markdownのリンクをコピー | `[タイトル](/pages/{id})`の形のMarkdown。ほかのページの本文に貼り付けます |
| URLをコピー | `https://…/pages/{id}`の完全なURL。チャットなどに貼るときに使います |
| 本文のテキストをコピー | 表示されている本文の文字だけ（Markdownの記号を除いたもの） |

タイトルの横のボタンではタイトルの文字列だけがコピーされます。

本文に`/pages/{id}`を含むものはすべてリンクとして数えます。`https://…/pages/{id}`のような完全なURLも、コードブロックの中も含みます。

## トップに表示するページ

ホーム画面（`/`）ではスペースの一覧の上にページを1つ表示できます。管理者が全員スペースのページを開いて「トップに表示」を押すと、そのページが全員のホーム画面に出ます。リンク集のようにチームの入口になるページに向いています。

- 選べるのは全員スペースのページだけです。表示中のページを全員スペース以外へ移したりゴミ箱に入れたりすると表示されなくなり、戻すとまた表示されます。
- ページを完全に削除すると設定も外れます。
- 表示するページはほかのページと同じように編集できます。MCPからも`update_page`で更新できます。どのページを表示するかはWebでしか選べません。

## ゴミ箱と編集履歴

削除したページはゴミ箱に移り、30日のあいだは元に戻せます。完全に削除できるのは管理者だけで、Webのゴミ箱から行います。上書きする前の内容は編集履歴として新しい20版まで残ります（[MCPで接続する](/libreno/getting-started/mcp/#ゴミ箱と編集履歴)）。
