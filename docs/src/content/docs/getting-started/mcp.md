---
title: MCPで接続する
description: ClaudeなどのアプリからMCPでLibrenoに接続し、AIにページを書かせます。
---

生成AIのアプリからMCPでスペースとページを読み、ページを作成・更新できます。ページのタイトルと本文を文字列で検索することもできます。接続はログインしたユーザー本人として行われます。Webと同じく、そのユーザーがアクセスできるスペースしか見えません。

接続先のURLは`<URL>/mcp`です（OIDC認証では`<APP_ORIGIN>/mcp`）。

:::note
MCPは無料プランのCPU時間の上限を超えます。MCPを使う場合はWorkers Paidを使ってください（[動作環境](/libreno/getting-started/requirements/#mcp)）。
:::

## Claudeで接続する

1. Claudeの「設定」→「コネクタ」でカスタムコネクタを追加する。
2. URLに`<URL>/mcp`を入れて接続する。
3. 開いたブラウザでlibrenoにログインし、接続を許可する。

## Claude Codeで接続する

OIDC認証では`<URL>/mcp`の代わりに`<APP_ORIGIN>/mcp`を使います。

1. 次のコマンドを実行する。

   ```sh
   claude mcp add --transport http libreno <URL>/mcp
   ```

2. Claude Codeで`/mcp`を開き、librenoを選んで認証する。
3. 開いたブラウザでlibrenoにログインし、接続を許可する。

## 接続の有効期限と切断

許可の画面は接続のたびに表示されます。接続の有効期限は30日です。期限が切れたらもう一度接続してください。

次のときは、そのユーザーのMCPの接続もすべて切れます。

- 管理者がユーザーのセッションを失効させたとき
- 管理者がパスワードを再設定したとき
- 管理者が多要素認証をリセットしたとき
- 本人がパスワードを変更したとき

その時刻までに許可した接続は`/mcp`で拒否されるので、接続情報を保存しているKVの反映が遅れて取り消しから漏れた接続も使えません。Webからログアウトしても、MCPの接続は切れません。

デプロイすると、MCPの接続情報を保存するKVネームスペースが1つ作られます。

## AIができること

| ツール | 内容 |
| --- | --- |
| `list_spaces` | 見られるスペースの一覧 |
| `list_pages` | スペースのページの一覧（本文なし） |
| `get_page` | ページの本文（Markdown）とメタデータ |
| `search_pages` | タイトルと本文の文字列検索 |
| `create_page` | ページを作る |
| `update_page` | タイトル・本文・フォルダを変える |
| `move_page` | ページを別のスペースやフォルダへ移す |
| `delete_page` | ページをゴミ箱へ移す |
| `list_trash` | ゴミ箱のページの一覧 |
| `restore_page` | ゴミ箱のページを元に戻す |
| `list_page_revisions` | ページの編集履歴の一覧 |
| `get_page_revision` | 編集履歴の1版の内容 |
| `restore_page_revision` | 編集履歴の版に戻す |
| `upload_attachment` | ページにファイルを添付する（2MBまで） |
| `list_attachments` | ページの添付ファイルの一覧 |
| `list_folders` | スペースのフォルダの一覧 |
| `create_folder` | フォルダを作る |
| `update_folder` | フォルダの名前を変える・同じスペースの中で移す |
| `move_folder` | フォルダを中身ごと別のスペースやフォルダへ移す |
| `delete_folder` | 空のフォルダを削除する |

### フォルダ

フォルダの作成・名前変更・移動・削除もMCPからできます。削除できるのは、中にフォルダと（ゴミ箱以外の）ページがないフォルダだけです。

### 別のスペースへ移す

ページとフォルダは移動用のツール（`move_page`と`move_folder`）で別のスペースへ移せます。フォルダは中のフォルダとページ（ゴミ箱のページを含む）ごと移ります。

個人スペースから全員スペースへのように見られる人が増える移動では、AIが利用者に確認してから`acknowledge_wider_visibility`を付けて呼ばないと失敗します。見られる人の広さは「個人 < 管理者のみ < メンバー指定 < 全員」の順に数えます。メンバー指定のスペースから別のメンバー指定のスペースへの移動も同じく確認が要ります（メンバーの顔ぶれは比べません）。

### 添付ファイル

MCPからはページへのファイルの添付（`upload_attachment`、2MBまで）と添付ファイルの一覧（`list_attachments`）も使えます。添付したファイルを本文に入れるには、返されたMarkdownを`update_page`で本文に書き足します。添付ファイルの削除はWebからしかできません。

### ゴミ箱と編集履歴

MCPからページを削除するとゴミ箱に移り、30日のあいだは元に戻せます。完全に削除できるのは管理者だけで、Webのゴミ箱から行います。

上書きする前の内容は編集履歴として新しい20版まで残り、そこから戻せます。ゴミ箱から完全に削除したページと30日たって自動で削除されたページは、履歴ごと消えるので戻せません。

### ページどうしのリンク

AIは`[タイトル](/pages/{id})`の形でリンクを書きます。リンクしているページを探すときは`search_pages`で`/pages/{id}`を検索します。この検索結果には、タイトルが一致したページとそのページ自身も含まれます。
